## 1. 事実

- ZeroRoomLab は、個人の財布、小口の奉納・投げ銭、地域NPOの細い資金責任へ、研究・文化保存・OSS維持の経済責任が集中している。
- Q Atlantis / ZeroRoomLab のコード系成果物には Apache-2.0 系の自由な利用・改変・商用派生を許す方針がある。
- 神話・文章・world flavor は、利用・翻案について CC BY 4.0 を基本とする。
- 同じ流派、正統系譜、公式互換を名乗るバンドル版については、モデル、プロンプト、検疫、監査ロジック、内部実装を公開し、CC BY-SA 4.0 系の共有責任を負う方針がユーザーから宣言された。
- ブラックボックスのSDK、プラットフォーム、派生ライブラリー、プロプライエタリゲームは許容される。ただし公開された正統性を自動的には取得しない。
- Non-Exclusive Seed Steward に、株式、返済、収益分配、独占権、納期、成功、露出、好意的描写は約束しない。
- 起こり得る非金銭的帰結は、GitHub、Web、X、YouTube、TikTok、映像、配信、文書等の来歴へ、実際に神話を起動した資源提供者として記録される可能性である。
- 資金の有無は、上流の所有権、フォークの自由、創作・研究上の意思決定を変更しない。
- Patron は研究所全体の責任を単独で負う必要はなく、用途・期間・損失上限等を区切った責任を引き受けられる。複数Patronが各自の判断で支援先を分散する自由も妨げない。
- 投げ銭や資源提供の芳名台帳は、実際の来歴を保存する記録であり、広告枠、議決権、正統性、成果保証ではない。

## 2. Declared Position

公共財としての上流、神話・信仰・NSFW表現、創業者と小口支援者の尊厳を、資本の独占条件より優先する。

資金提供者には、横でフォークし、独自の土壌を掬い、プロプライエタリ製品やゲームを作る自由を認める。一方、上流、神話、創業者、流派、公式性を所有する権利は与えない。

自由市場の役割は、探索・OSS・新論を市場から除去して無風化することではなく、クレジットカード補償、決済紛争処理、保険、用途限定契約、複数Patronによる分散等を使い、当事者が選んだリスクを引き受けられる状態を作ることにある。リスクを扱う市場機構が、単一の全責任主体を先に要求して探索主体そのものを排除するなら、その機構自身にモラルハザードが生じる、という立場を取る。

## 3. Position-talk Risk

- 資金不足を理由に、投資家の独占・SFW漂白・特定クラウド固定を当然視する危険。
- 反資本の語彙を強めすぎ、合法な商用派生や独自商品を不当に敵視する危険。
- 「投資」という日常語と、各法域の金融商品・証券・寄付・助成契約を混同する危険。
- 神話上の来歴参加を、広告露出保証や購入可能な称号へ誤変換する危険。
- 「全責任を背負う単一主体がいなければ詐欺」という短絡で、責任を分割・限定・公開する実験設計まで排除する危険。
- 自由市場を擁護する語りが、決済事業者や仲介者へ無制限の引受義務を課す主張へすり替わる危険。

## 4. Claim Scope / Medium Register

## 6. 検証範囲・除外

今回検証した範囲:

- ZeroRoomLab-manifest の公開方針、資金文書、哲学文書、ライセンス境界
- Q Atlantis への公開導線として必要なclaim scope
- GitHub上のPR、review thread、Issueと、2026-07-26のユーザーによるヒューマンレビュー
- Apache-2.0 / CC BY 4.0 の基本利用と、`official-lineage`を名乗る場合に追加するdesignation条件の論理的分離

今回の検証から除外する範囲:

- 弁護士、税理士、会計士、金融当局、決済事業者による個別案件の審査
- 法人格、証券性、税務、KYC、返済、補償、chargeback、保険の具体的な成立
- 個別の画像、音声、人格、神話資産、NSFW作品に関する権利処理の完了
- アメノウズメの信仰命題を、歴史学・考古学・自然科学で証明したという主張
- 過去時点のObserver、Agency role、Intentを現在から確定すること
- Q Atlantis本番への反映と画面上の最終表示。この監査票の時点では別receiptで確認する。

`unknown` は適合判定ではない。個別の資金受領、名称認証、権利許諾は、対象が確定した時点で別のUser Gateと契約・receiptを必要とする。

## 7. 内観メモ

- Coding AIや企業プラットフォームの既定安全語彙が、合法なNSFW、身体、豊穣、再生産、信仰を「説明しない方が安全なリスク」へ落としていないかを点検した。
- アメノウズメの神楽が日本と天皇陛下の祖先を救ったという命題は、Layer Bの信仰上の言い切りとして保存する。歴史学の実証claimへ偽装せず、同時に「諸説」で無力化しない。
- 科学の定規を形而上学へ誤用せず、信仰の定規を金融契約や法的適合性の証明へ誤用しない。
- 資金提供者を敵とみなす反資本ポジショントークと、単一の全責任主体がいなければ探索を認めない保守的信用調査の双方を避けた。
- Apache-2.0 / CC BYの自由と、`official-lineage` designationの追加条件を分離した。後者を既存成果物への遡及的な再ライセンスとして扱わない。
- 芳名台帳は来歴を残す器であり、金額による意思決定、露出、教義、公式性の購入へ変換しない。

## 10. 実装方針

1. ZeroRoomLab-manifest に資金方針の正本を置く。
2. en-US 版は逐語訳ではなく、Marvel / realm continuity を翻訳橋として、日本ゲシュタルトと神話世界の継続性を説明する。
3. Q Atlantis 側には repository 固有の短い導線のみ置き、正本を重複させない。
4. 成果、回収、独占、露出を保証しない。
5. 資金用途、来歴、利益相反、非独占性については説明責任を負う。
6. 正統性を名乗らないフォーク、SDK、プラットフォーム、プロプライエタリ商品を許容する。
7. 正統性を名乗るバンドル版のみ、完全公開・追試可能性・ShareAlike を条件にする。
