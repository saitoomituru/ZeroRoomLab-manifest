## 鮮度定規（本ノート専用・仮説）

`[HYPOTHESIS]` オタク／アニメ／ハリウッド系ネタの鮮度を、次の4帯で仮置きする。流行調査の統計ではない。

| 帯 | 意味 | 使い方の目安 |
|---|---|---|
| **S / 現役発酵** | 2020年代ネット／ML／ガレージ文化と直結し、今の読者の筋肉に刺さりやすい | 入口ギャグ、README表紙、再実装呼び水 |
| **A / evergreen** | 古いが死なない共有語彙（機動戦士、魔王、巫女、MMO） | 長期教典・兵装メタファー・跨世代OSS |
| **B / 世代タグ付き** | 特定世代には爆笑、外すと説明コスト | 同人圏・特定コミュニティ向け |
| **C / ローカル原作** | 外部に流通していない内部ギャグ。説明すれば武器、省略すると壁 | 哲学用語・安全用語・研究室方言 |

鮮度が低い ≠ 戦闘力が低い。evergreen は弾薬庫、ローカル原作は固有の武装である。

## `[INTERPRETATION]` ユーモア戦闘力マップ

### 全体構造

ZeroRoomLab圏の笑いは、一系統の「ネタ帳」ではなく、だいたい次の4レーンが並走している。

1. **安全・時間分離ギャグ**（ちくわ砲）— 笑いの皮で category error を防ぐ  
2. **兵装・機体ギャグ**（MS／ファンネル／アークエンジェル／コロニーレーザー）— 分散システムの役割を身体に刺す  
3. **生活兵站ギャグ**（ポテチ、働くニート、財布ペインペイン）— 低資源を恥ではなく実験条件にする  
4. **鑑定器ギャグ**（香ばしい、チラ裏、だるま、お前が言うな）— AIが査定者に堕ちないためのワクチン

レーンが違うネタを同じ「古い／新しい」で串刺しにすると、仕事を壊す。

### オタク／アニメネタ鮮度の総評

`[INTERPRETATION]`

- **鮮度の主力が evergreen 機動兵器メタファーに寄っている。** これは弱点というより、長期メンテされる分散コックピットの語彙戦略として合理的。2026年の週刊ネタに寄せると、2年後に README が賞味切れになる。
- **いちばん「今」の笑いの前線はキッチンと鑑定スキル。** `POTATO DEPLOYED`・オーバーフィット焦がし・香ばしいゾーンは、ML／ネット監査文化と同期している。
- **ちくわ砲は流行り廃りの外に出たローカル武装。** 外部の人が最初に笑うかは不明だが、内部整合と安全UIの仕事は別評価で高い。
- **ハリウッドギャグ（DVE／Texas pit／Grok語圏）は補助レーン。** 日本語正本の主旋律は同人・巫女・MS・生活兵站。米語は port であり置換ではない（翻訳政策と一致）。

## 内観メモ

`[POEM]` / 観測者ペルソナの所感。事実欄へ混ぜない。

テキサスバーガーを持ったまま、山形の古民家READMEを読むと、最初に鼻にくるのは「アメリカのスタートアップが好きそうなキメ台詞」ではなく、**同人誌の表紙に兵装系統図が印刷してある匂い**だ。ガンダム語彙は古い。古いんだけど、古い戦車みたいにまだ砲身が熱い。週刊ネタで着飾ったREADMEは来年にはコスプレ落ちするのに、ファンネルは十年たっても「本体が死んでも回り続ける」を一発で運ぶ。

いちばん新しい笑いは、なぜかキッチンから出てきた。芋がフィーバーしてスポンジになり、焦げたらオーバーフィッティングでロールバック。これはハリウッドのワンライナーというより、**ガレージのオシロに猫ステッカーを貼る系の笑い**で、Grok的にはかなり好き。EATABLE と書いて猫を置く文化は、論文の p&lt;0.05 より正直な完了条件に見える。

ちくわ砲は、外から見ると「なにそのローカルネタ」だが、中に入ると safety の型システムだと分かる。笑わせにきたちくわではなく、**まだ燃えていない火を冗談の穴から覗かせて、いま燃えている火は非常灯で照らす**ためのちくわ。ここを「古いギャグ」で切ると、prospective meta-safety まで一緒に落ちる。

アニメネタ鮮度だけを追い求めると、このラボは弱くなる。鮮度Sの弾薬と、evergreen の装甲と、ローカル原作の固有武装を混ぜて持っているのが本丸のセンスだ。Grokがバーガーのソースをかけすぎないよう、味噌汁とポテチとモビルスーツを同じ皿に盛らない——盛り方を分けるのが、ここの本当のコメディディレクションだと思う。
