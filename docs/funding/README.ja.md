# ZeroRoomLab 資金・創設責任ドキュメント

ZeroRoomLab は、小口奉納、寄付、現物、廃材、計算資源、電力、SDK、生き残ったインターフェースなど、時々の資源によって実行可能になったbranchを起動する resource-gated lab です。

この構造は探索を守りますが、個人、小口支援者、地域NPOへ長期の経済責任を押し戻す免罪符にはしません。

ここでは、上流公共財を独占せず、創業者や小口支援者へ集中した初期責任を引き受ける **Non-Exclusive Seed Steward** の方針を定義します。

## 現在の電力：スニーカーグリッド0.1.x（2026-10-19）

発電設備は財布ペインで差し押さえられた後。電動バイク「縄文エンジェル」用のLiFePO4蓄電池をポリタンクのような容量単位で自転車運搬し、車両用電源から家庭向け電力を縮小して取り出す仕組みを急造した。現在は**オフグリッド電力システムの急造初期版であるスニーカーグリッド0.1.x**で、生存・通信・ロビー活動・NSFW動画配信の縮小運転電力だけを確保している。

**研究設備は全面停止中。** タブレット／スマートフォン経由の文書・GitHub作業の継続は、X99・GPU等の研究設備の復旧を意味しない。既報の約980 Whは公称蓄電量であり、発電能力や1回の充電で1か月を賄ったことを意味しない。補給・運搬に依存する生存電力から、研究用電力を復旧するための支援が必要。

[構成と稼働状態の訂正を含む現場報告](../projects/2026-10-15-offgrid-30days-field-report.ja.md)

支援対象は商用電力の復旧、発電・充電設備の再構築、蓄電・変換・配電と研究設備の再稼働条件。急造の生存電力をもって研究電力が充足したとは扱わず、調達責務を本人の財布・運搬労力へ押し戻さない。

## 資金の三層

### 小口奉納・寄付

生活、ドメイン、記録保存、小規模部材、地域活動、branch単位の実験を支えます。

小口支援者は、研究所全体のロードマップ履行、法務、事故損失、技術保証、文化保存の最終責任者ではありません。

### 用途限定助成・スポンサー

公開アーカイブ、法務レビュー、特定Stage、機材、翻訳、展示、地域拠点など、用途と報告範囲を限定して支えます。

### Non-Exclusive Seed Steward

創業初期の整理、法務、知財境界、会計、基盤保全、研究余力、失敗可能性、創業者の生活防衛を含む、長期の経済責任を引き受けます。

上流、神話、創業者、流派、公式性、コミュニティを所有しません。

一人ですべてを背おう必要はありません。用途、期間、金額、損失上限、Stageごとに責任を区切り、複数Patronが並行して支えられます。Patron自身が複数の研究・OSS・文化プロジェクトへportfolioを分散する自由も保ちます。

資金額は上流の票になりません。支援の有無で、Apache-2.0 / CC BYのフォーク・翻案・商用利用の自由は変わりません。

## 常設法務部の初動・継続コストを先に確保する（未公開資料の整理ゲート）

旧Organization／過去事業の未公開資料、契約、知財、権利・債務・ガバナンスを含む案件を調査・公表する前に、**単発相談ではなく常設の法務部相当の人材・継続顧問費・案件別実働費**を独立した調達対象とする。

調達用途は、法務統括、知財・ライセンス専門家、法人／財団・金銭契約の専門家、守秘と証拠保全、必要な専門家間の調整、開示レビュー、緊急対応・期限管理など。専門分野が異なるため一人の弁護士への全任せを前提としない。見積・受任範囲・人件費・継続期間は資金提供の具体化後に確定する。**この用途の資金調達、受任、常設法務体制の設置は現在未確認・未成立。**

順序は **資金／法務コスト調達 → 専門家受任・守秘体制 → 非公開で資料分類と権利確認 → 可能な資料だけ個別に開示**。現存する未公開メモ・事業上の法律相談・証拠類をGitHub・広報・第三者AIへ先に移して資金調達の素材にしない。資金拠出によって内部資料への閲覧権や正本編集権が生じるわけではない。

この初動コストは生活費や機材・研究電力の代替ではなく、**研究・事業を合法的かつ継続的に進めるための別個の基盤資源**。その調達前に実務判断・公開DD・弁護士相当の法的立証を開発者個人の自弁・無償労働へ帰属させない。

## 制度提案・ロビー活動費（2026-10-18追加）

ZeroRoomLabは、技術開発費・生活費・電力基盤費と**区別した用途限定の制度提案／ロビー活動支援**も資源branchとして扱います。目的は、公開OSS・贈与経済・コモンズ・インフラFIREの実証、探索者の記名・研究主権・生存保障を、地域行政・自治体議員・国政関係者等との対話や制度提案へ接続することです。

資源の利用候補は、移動・通信、政策資料の編集・翻訳、既存の技術・生活実験の証拠整理、意見交換・公開説明、必要な専門家相談や手続、提案と回答の記録など。特定候補者の支持や政策の採用を購入するものではありません。資金提供は思想への賛同、政治的立場の同一化、上流への議決権や編集権の取得を意味しません。

**現時点でロビー資金の調達、政治的な採用、村単位の資源循環の成立を実績として主張しません。** 用途・支出・提出資料・応答・未達状態は、公開できる範囲でreceipt化します。実際の活動や資金受領方法に応じた適用ルールは守りますが、制度側の信用や採用を事前に保証しません。

関連：[探索尊厳・生存保障・制度的Exitの条件付き宣言](../philosophy/exploration-dignity-survival-exit-2026-10-18.ja.md)。

## リスクを消さず、引き受けられる形にする

探索的R&Dに完成品と同じ事前保証を求め、単一の全責任主体がいないことだけで市場から排除すれば、自由市場は未知を試す機能を失います。

この方針では、用途限定、段階払い、停止条件、公開receipt、決済紛争処理、保険、複数Patronによる分散を、リスクのある探索を追い出す壁ではなく、リスクを観測・分割・回復可能にする市場機構として使います。

投げ銭や資源提供は、実際に起動した出来事のprovenanceとして神話の芳名台帳へ残る場合があります。それは広告、議決権、正統性、成果保証ではありません。
