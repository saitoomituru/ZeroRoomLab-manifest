# ZeroRoomLab 資金・創設責任ドキュメント

ZeroRoomLab は、小口奉納、寄付、現物、廃材、計算資源、電力、SDK、生き残ったインターフェースなど、時々の資源によって実行可能になったbranchを起動する resource-gated lab です。

この構造は探索を守りますが、個人、小口支援者、地域NPOへ長期の経済責任を押し戻す免罪符にはしません。

ここでは、上流公共財を独占せず、創業者や小口支援者へ集中した初期責任を引き受ける **Non-Exclusive Seed Steward** の方針を定義します。

## 資金の三層

### 小口奉納・寄付

生活、ドメイン、記録保存、小規模部材、地域活動、branch単位の実験を支えます。

小口支援者は、研究所全体のロードマップ履行、法務、事故損失、技術保証、文化保存の最終責任者ではありません。

### 用途限定助成・スポンサー

公開アーカイブ、法務レビュー、特定Stage、機材、翻訳、展示、地域拠点など、用途と報告範囲を限定して支えます。

### Non-Exclusive Seed Steward

創業初期の整理、法務、知財境界、会計、基盤保全、研究余力、失敗可能性、創業者の生活防衛を含む、長期の経済責任を引き受けます。

上流、神話、創業者、流派、公式性、コミュニティを所有しません。

## 法的な器について

この文書は思想・運用方針の正本です。株式、寄付、助成、融資、信託、財団基金、回収上限付き助成その他の法的手段を自動的に成立させる契約書ではありません。

具体的な金融商品、証券、税務、法人、会計、返済、持分等を使う場合は、採用する法域と個別契約で別に定義します。
