## 資料と記録の扱い

- 原文リンクは[資料台帳](sources.json)に登録する。外部記事の全文転載はせず、発行元の原文へ直接リンクする。
- GitHub原文は固定commit版と最新版を並べる。固定版は今回の読書対象、最新版は差分確認用。
- 原文の記述、読者の所感、agentの解釈、比較判定を分ける。資料のリンク登録は原文の全主張を検証したという意味ではない。
- 外部記事は2026-10-23に本文へのアクセスと掲載情報を確認。本人発言・他者発言・編集者記述は読書時に箇所ごとに区別する。
- 最古資料の探索、本人著作・スライドの追加、リンク先からの追加資料は未完。未確認を不存在としない。
- この研究フォルダーはGitHub文書の整理単位であり、VS Code workspaceや新しいruntimeの作成ではない。

自己監査：今回は原文への導線と本人読書工程を設ける局所的な整理。双方の理論・哲学・実装状態の判定は変更していない。
