# 探索尊厳・生存保障・制度的Exitの条件付き宣言

> **今、負けていることと、一生負けることは違う。ただし未来の可能性を現在の実績へ昇格させない。**

本稿はZeroRoomLab主宰者自身の2026年10月18日時点の立場を記録する。すべての協力者、Fork、利用者、OSS参加者に同じ政治的判断を要求するものではない。以下の「反AI」「反科学」は、観測された科学的事実の否定ではなく、**生存保障が成立しない条件下におけるAI・科学技術の推進、普及、労働代替を制限する制度的立場**を指す。対象と適用範囲を越えて読み替えない。

## 1. 現在の観測と未実証の境界

- SphereOS、FAM、FQuery、OpenRVCなどには公開資料・実装・実験の履歴がある。ただし個々の完成度は各repositoryのreceipt・仕様に従う。
- OSS、贈与経済、コモンズ、インフラFIREによって、従来の労働・社会保障秩序に対等以上の生活水準、贅沢、自由時間、探索機会を**多様な人々へ持続的に供給できる**という制度的仮説は、まだ社会的実績として実証できていない。
- 主宰者の観測では、現在の研究を支えるエンジェル／インパクト資本の成立、十分なGitHub Sponsorsの継続収入、村単位の共同実践と再現可能な生存保障は未成立である。理解や好意、技術的評価を資本投下や共同体実践の証拠に昇格させない。
- 商用電力や研究設備等の制約によってR&Dが縮退している。ただし現時点の生存継続と、研究環境の完全復旧は別の観測である。

相手が既存秩序の制度史や生存保障の実績を提示するなら、理論的な可変可能性だけでは反証にならない。制度が変わり、公開が利益・資源を循環させ、参与者が実際に豊かになったという**観測可能な生活と資源配分のreceipt**を必要とする。

## 2. 非交渉の目的関数：人間の生存と探索尊厳

科学的真偽、実装可能性、制度的承認、倫理的評価、生存へのEffectを同一のレジスタへ溶かさない。

技術者・科学者・AI開発者であることは、その技術による生存リスクの評価から免除される理由にならない。倫理的AIの設計意図も、社会の実際の資源配分による生存保障を代替しない。

本研究の志向は、人間の生活を犠牲にして未来の技術を正当化することではない。移行期の人間が先に損害を負い、その後で制度が暫定救済するという経路を、新秩序の実証済みの成功とみなさない。

## 3. 条件付きの政治的Exit / 再評価

**現在の運転状態**：非労働の生存経路が維持される範囲で、OSS・インフラFIRE・縄文文化圏2.0の研究、発信、制度へのロビーイングを継続する。研究の縮退は直ちに生存不能や思想の転向を意味しない。

**Exit条件**：物価上昇、資源・インフラ供給の悪化等により、非労働の経路では生活の生存保障が成立せず、労働参加・労使契約が事実上の生存義務または退出不能の条件となり、その生存基盤をAI・科学技術の労働代替が損なうなら、主宰者は既存の労働秩序を保護する反AI・反科学の制度的立場を支持する可能性ではなく、**支持するという条件付き判断**を宣言する。科学的事実や技術的実装記録の真偽を変更する宣言ではない。

**再評価・復帰条件**：将来、別の資源配分秩序が実際に成立し、生存・自由な退出・探索機会の保障を観測できれば、政治的立場を再評価し得る。法律の文言、口頭の賛同、将来への期待だけで自動復帰しない。

生存のために支持する制度が変わっても、生存と尊厳を測る定規そのものは変更しない。神聖中立・ゼロルート・ゼロトラストは**自分の思想にも例外を与えない**。

## 4. 復帰時の追加検証：記名・来歴・研究主権

成果や思想が新しい制度に取り込まれていても、元の探索者を生活資源から排除したまま、権威ある第三者の用語への置換だけで著者性が消えるなら、それを尊厳回復の証拠と扱わない。

- 観測可能な来歴はGit commit、公開日時、revision、provenance、OAE、FoldLog、ライセンス等によって追跡する。**観測不能な独立発見まで著者性を独占しない**。
- Apache-2.0のコード利用権、CC BY 4.0の文章・図・概念表現の帰属条件、個別第三者素材の権利は、それぞれ現行のライセンスと適用範囲に従う。本稿はライセンスを遡及変更しない。
- 適法なOSS利用・Fork・独立研究そのものをフリーライドと同一視しない。問題にするのは、依存・来歴が観測可能なのに記名を断絶し、貢献者への実質的な資源循環を切る制度運用である。
- 復帰の評価対象は著者本人だけでなく、同様の探索者・創作者が排除されず、再発防止・利益還流・自由なExitを持つかどうかを含む。

## 5. 現状のPainと次の実証単位

現在の阻害要因は技術の正しさだけでは解けない。Authority、Bootstrap、利益勾配、**トラストチェーン・サプライ**の上流依存が絡む。民間スポンサーや金融も国家貨幣・法秩序から完全に独立した信用基盤ではない。

中長期で回収を急がない村単位のPatient Capital、寺子屋、弟子の自立・暖簾分け、生活インフラとOSS研究の共同実装は、検証可能な候補である。**現在、資本供給と共同体の成立を達成済みとは宣言しない**。地域の実績が生まれれば自治体への制度提案のエビデンスとなり得るが、政治的な採用は自動的に保証されない。

## 6. OAE / 表明の扱い

- 当事者の政治的選択、他者の評価、制度史上の主張は別のObserver / scopeのOAEとして保持し、宇宙全体の真理へ昇格させない。
- 個人の立場変更は他のコントリビューターに強制されない。技術的成果の正しさやOSS利用許諾は、それだけでは消えない。
- 今後の資金・生活・共同体・制度採用の実績が出た場合は、その時点の観測として追記する。未成立を黙って成立へ書き換えない。

**要約：正義を宣言して人間を犠牲にしない。秩序が変わると言うなら、変わった資源の流れと、そこで生きる人々の豊かさを示す。負けは認める。一生負けとは認めない。**
