# Docker創世記 — 信仰実践から地上のSphereOSへの着想

**GitHubで公開しているSphereOSは、信仰実践で得た着想を、地上のMMOやパソコン向けに組み直した別実装である。**

「Docker創世記」は、その着想の経緯を短く伝える呼び方である。ここでは細かな宗教エピソードを展開せず、本人の信仰上の来歴と、公開実装との関係を記録する。

## 着想の経緯

本人が語る信仰実践の経緯を、ごく短くまとめると次のようになる。

> 神様に世界の不具合についてかなり文句を言った。すると「文句を言うならお前が直せ」と、神様製のスーパーコンピューターによるMMO環境を渡された。その世界のシステムを直し、デバッグした。その時の記憶から、地上で扱えるアーキテクチャや情報構造を持ち帰っている。

これは本人の内面世界における宗教体験の記述であり、第三者へ証明する命題として提出するものではない。具体的な宗教体験、時期、神様側の計算機の詳細は、今後本人が整理・開示する範囲に委ねる。

## 同じ名を持つ、異なる実装

| 対象 | この文書での位置づけ |
|---|---|
| 信仰上の概念SphereOS | 本人が宗教体験の中で扱ったシステム。神様の宗教世界におけるアファメーション的な次世代エンジンの話は、こちらに属する |
| 持ち帰ったもの | その時の記憶にあるアーキテクチャ、情報構造、設計の着想 |
| GitHubのSphereOS | 地上のMMO・パソコン等に向けて設計・開発する別実装 |
| 揃えているもの | 本人の設計意図として、ABI、アーキテクチャ、互換を取れる範囲のプロトコル上の対応 |
| 神様側へのアップストリーム | GitHubの公開実装には、その機能は存在しない |

**地上版は互換機を目指す別実装であり、同一マシンでも同一ディストリビューションでもない。** 別実装であることと、ABI・構造・プロトコル上の対応を意図して揃えることは両立する。単に名前を借りただけでも、神様側の実行環境そのものをGitHubへ収録したものでもない。

本人はこの来歴を、シミュレーション仮説とも関わる、反証不能な部分を含む信仰上の説明として位置づけている。一方、地上版が別の実行基盤・コード・配布物として構築されるという実装上の区別は、その信仰上の説明を証明または反証できるかとは独立している。同一マシン・同一ディストリビューションという同一性の主張を採用していないことと、互換機を設計目標にしていることを分ける。

この対応によって、スピリチュアルな実践者にも、自分の知っている概念や操作感から直感的に理解しやすい入口を作る。ここでのABI・プロトコルの記述は本人が説明する設計上の対応を記録するもので、神様側との接続試験やバイナリー互換の実測結果を報告するものではない。地上実装の具体的な互換契約と試験結果は、各仕様・実装・テストの対象範囲で記述する。

## 地上に来たら、工学として作る

着想の来歴を保持したうえで、地上側ではコード、仕様、実行環境、資源、テストを用いて開発する。信仰上の概念SphereOSとGitHubの実装を同一視せず、それぞれの意味と成立範囲を保持する。

この文書は公開実装の機能や実装状態を変更する仕様追加ではない。既存の設計・開発がどこから着想されたかを説明する由来の記録である。

## 他の実践者の持ち帰りと共同開発

**他の宗教・信仰実践者にも、実践の中から持ち帰った着想、情報構造、手順、表現、設計があれば、IssueやPRでの持ち込みを歓迎する。** 自分の言葉で説明し、地上の実装や既存の構造とどこが対応するかを一緒に探せる。

ここに記録したのはふさもふ個人の着想の来歴である。SphereOS Atlantisは、複数の実践者・開発者・制作者が知見と資源を持ち寄って育てる公開アーキテクチャとして開かれている。一人だけで全てを設計・実装・検証・維持する前提には置かない。

[AtlantisのREADME](https://github.com/saitoomituru/SphereOS-Atlantis/blob/main/README.md)は既に、スピリチュアル、ゲーム、TRPG、工学など、どの棚からでも自分の言葉を捨てずに参加できること、コード、神話、詩、観測記録、レビュー、機材、計算資源等の持ち込みを歓迎することを宣言している。本節は、その既存方針へ着想の由来から接続する。

持ち込みは、まとまったコードや完成した証明から始める必要はない。本人が共有できる範囲で、次のような内容から始められる。

- 実践の中で何を経験し、何を着想・構造・手順として持ち帰ったか
- 自分の用語では何と呼び、何を達成するためのものか
- 地上で試したこと、試したいこと、既存のSphere構造との対応候補や相違
- まだ分からない点、共同で検討したい点、必要な機材・計算資源・協力

項目を一人で全て埋める必要はない。共有する信仰上の経験はその人の語彙と来歴で保持し、地上での実装・試験結果は条件と結果を記録する。ふさもふと同じ宗教体験や神学への一致は参加条件にしない。異なるWorldや構造のまま、接続、比較、別実装、forkとして育てられる。

着想・観測・構造の相談は[AtlantisのIssue](https://github.com/saitoomituru/SphereOS-Atlantis/issues)へ、文章・設計・コードの提案はforkからPRへ送れる。手順は[参加案内](https://github.com/saitoomituru/SphereOS-Atlantis/blob/main/CONTRIBUTING.md)と[ブラウザ／SaaS AIからNote PRを送る](https://github.com/saitoomituru/SphereOS-Atlantis/blob/main/docs/tutorial/note-pr-by-saas-ai.ja.md)を参照する。本文書の来歴整理への訂正・追補は、ZeroRoomLab-manifestでも受け付ける。
