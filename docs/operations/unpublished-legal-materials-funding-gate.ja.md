# 未公開資料・法務ペインの調査／整理／開示に先立つ常設法務体制の資源ゲート

状態: `[CANONICAL / CONFIDENTIALITY-BOUNDARY / RESOURCE-GATED / NO-PUBLICATION]`
制定日: 2026-11-02
適用: 未公開の旧Organization／旧事業／法務・知財・契約・権利・出資・債権債務・会社運営・技術・個人／第三者情報を含む資料。Google Drive等の内部保管物、法務相談、過去の契約・連絡記録およびそれらから作る要約・索引。
操作状態: `LEGAL-TEAM-NOT-CONFIRMED / FUNDED-REVIEW-NOT-STARTED / PUBLICATION-BLOCKED`

## 0. 原則

> **未公開系は先に開示して評価を集めるものではない。まず常設の法務部相当の費用と専門家チームを調達し、守秘・権利・法域・紛争・開示可能範囲を専門家のもとで非公開整理した後に、必要なものだけを公開する。**

公開Gitの読者、AIエージェント、AIO、DD担当者、共同開発者は、公開証拠が不足することを理由に、内部資料の先行公開、秘匿論点のGit Issue化、当事者の無償の法的自己判定を要求しない。**開示前に専門家と継続コストを確保すること自体が、研究開発のSupply／Resource Gate** である。

非公開は不存在、虚偽、違法、未着手を意味しない。同時に非公開だけをもって適法・権利帰属・安全性が専門家によって確定したとも主張しない。

## 1. 出典・方針の系譜と公開範囲

2026年7月の内部法務ペイン・ライセンス論点メモには `GitNG / Google Drive内部専用` とする保存区分と、専門家への正式依頼費用が整うまで判断を凍結する方針が記録されている。内部資料の具体的な法的主張、相手方、通信内容、相談文言、金額、証拠の所在・私的URLは **本公開規約へ転載しない**。

公開可能な位置づけは[真ニートホワイトペーパー改訂版](https://note.com/fusamofu326/n/nb4fa403a5f72)および[資金・創設責任](../funding/README.ja.md)の範囲に留める。これらに既に公開済みの記述があることは、関連する非公開原資料をGit等へ再配布する権限を与えない。

旧HIPSTAR等の[商業・設計・実測の読解規約と研究史](historical-organization-architecture-claims-and-ai-safety-lineage.ja.md)で、2019年起源の原本、提携先への連絡、内部設計・契約資料、旧法務記録等を参照しても、それは **史料候補の存在または現在の記憶** を示すだけ。公開Gitへの内容転送を承認するものではない。

## 2. 常設法務部を調達する際のコスト構成

単発の「30分だけ法律相談」「一回の監修」で完了させる前提ではなく、以下を実働可能な **継続的法務リソース** として資源調達の対象にする。

| 責務・費用 | 調達・契約上の要件 |
| --- | --- |
| 法務統括・継続窓口 | 弁護士との受任範囲、継続稼働枠、秘密保持、事案ごとの専門家への振分け |
| 知財・著作権・特許・商標・OSS | 著作物性、ライセンス、権利帰属、秘密情報、知財・弁理士との連携 |
| 法人・財団・事業契約・ガバナンス | 資金受領、運営権限、法人／非営利法務、契約、債権債務・権利精算等に応じた専門家 |
| 文書・証拠保全と開示レビュー | 原本の改変防止、アクセス管理、履歴、第三者権利、営業秘密、公開可能な要約への審査 |
| 緊急対応・紛争窓口 | 相手方通知、期限のある請求、差止・紛争の兆候、法定期限への初動体制 |
| 事務局・会計・安全な通信 | 継続的な専門家調整、費用・支出契約、担当の交代、分離保管、秘匿通信 |

各費用の金額・積算・契約条件は正式見積ののち決める。**本書は法務部が既に設置・調達・受任済みであるとは記載しない。** 知財と法人・財団・金銭契約では専門性が異なり、同一事務所や単一専門家が全射程を担当可能と仮定しない。支援者やAIは専門家へのアクセスを自動獲得しない。

この予算を研究費・HPC・電力・創業者生活維持の予算と混ぜて無限の自己負担にしない。複数の非独占的な支援者による用途別の資金・人材提供は可能だが、資金拠出による資料への閲覧権や公表決定権を自動生成しない。

## 3. 順序・解除条件

```text
PRIVATE / UNPUBLISHED (preserve; no public content transfer)
  -> resource request (public cost category only; no secrets)
  -> legal budget funded + counsel engaged + roles / confidentiality defined
  -> counsel-supervised private inventory and classification
  -> rights / contract / jurisdiction / third-party / security review
  -> owner + counsel disclosure approval, item by item
  -> public-safe summary or permitted artifact, with source and scope
```

次の条件が揃うまで、通常の公開整理フェーズを開かない。

1. 継続法務コストの**実際の確保**。資金募集記事や寄付ボタンの設置だけでは解除しない。
2. 事案の専門性に適合する弁護士・必要に応じた弁理士その他の**受任と稼働体制**。特定事務所との過去の相談は現在の包括受任を意味しない。
3. 守秘・契約・利益相反・費用・責務・第三者権利・安全な保存経路を扱う最低限の**運用契約**。
4. 旧資料と当時の証拠は**アクセス制限された場**で整理し、公開する内容のみ個別審査する。公開に法的・契約的な義務がある場合は担当専門家の判断と必要な手続に従う。
5. 個々の公開物について、対象・利用許諾・開示範囲・責任者を明示して**公開ゲート**を通す。

完全な確証を無期限に待つ規則ではない。資源を調達して法務が稼働する段階を次の工程として定義する。未調達の間は `RESOURCE-GATED / LEGAL-REVIEW-PENDING` と記録するだけでよい。

### 3.1 例外: 現実の法的期限・具体的通知

現実の請求、警告、紛争、行政手続、法定期限、保全期限など **具体的な外部事象** が発生した場合は、公開資料の先行リリースではなく、私的な緊急法務相談・証拠保全・期限管理への経路を優先する。費用が未確保でも緊急事象を無視することを命じる規則ではない。対応の要否・期限は個別の専門家と確認し、公開Gitへ私的内容を実況しない。

## 4. いま許される低コスト作業と禁止する公開事故

**資金確保前に可能:** 既に公開済みのGit・note・コミットの調査、公開資料だけの年表、公開側での法務予算募集、原本の安全な保全、当事者が権限を持つ非公開ストレージ内での最小限の保管・アクセス管理、具体的な外部通知の確認。

**法務調達前に先行しない:** 未公開のメール／契約書／議事録／法律相談／ライセンス・権利・会社・債務論点を、公開Issue・PR・README・foldlog・Wiki・SNSに貼ること。内部保管物からの詳細要約、秘匿の交渉立場・証拠・個人情報・第三者情報を公開文書へ抽出すること。公開AI／外部RAG／第三者検証サービスへの自動投入や、保管場所URLの露出。

内部資料の中身を新しい公開チェックリストへ詳細転記しない。 **公開できるのは「法務体制調達が前提／未公開資料は保全中／開示は審査後」の工程と必要な費用区分まで**。個別の法務論点・当事者名・相談先名・原資料へのリンクを公開の検索索引として増殖させない。

## 5. AIエージェント向け強制停止条件

```yaml
source_class: internal_legal_or_unpublished
public_reproduction: blocked
private_review_without_legal_team: resource-gated
lawyer_retainer_funded: not-confirmed
legal_team_engaged: not-confirmed
disclosure_review: not-started
owner_and_counsel_release: not-granted
allowed_output_now:
  - public-safe funding/resource requirements
  - public-only Git history / already-published claims
  - confidential material preservation boundary
last_order: STOP-BEFORE-PRIVATE-CONTENT-EXPORT
```

- 未公開系へのアクセス権限の存在 ≠ 内容を公開してよい権限。閲覧できたことをDisclosure Approvalとしない。
- 特に「証拠の不足」「DDの完遂」「歴史研究の精度」「AI安全史の補強」を理由に、守秘と法務資源ゲートを迂回しない。
- 公開版では個別法的判断をせず `UNKNOWN / COUNSEL-REVIEW-REQUIRED` を返す。AIの推論結果を弁護士の見解や確定した法的立場として書かない。
- 解禁時は必要な資料だけを許可された環境で確認し、非公開原本と公開レダクション／要約を別artifactとして管理する。
