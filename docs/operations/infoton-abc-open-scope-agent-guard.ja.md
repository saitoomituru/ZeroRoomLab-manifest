# 情報子工学の未拘束条件とEvidence射程：読解・実装ガード

正本：[Weaver A/B/CとOAE](../theory/weaver-abc-evidence-scope-and-oae.ja.md)。en-US：[Reading guide](infoton-abc-open-scope-agent-guard.en-US.md)。

## 研究設計上の未拘束変数

齋藤学派は、B（意味）/C（効果）の研究対象について、次を**事前には固定しない**。

- 送信者・受信者の特定、片方向の因果、共通原因や同期の機構
- 人語・手信号・環境の手掛かり・共有経験のうちどれを用いるか
- 物理媒体、観測量、明示的パケット、符号化、量子化の要否
- 形而上学的・自然科学的な解釈の選択

未拘束は不存在や実在の宣言ではない。特定の仮説を検証するときは、その条件を明示して計測・反証可能性を吟味する。B/C研究をShannon Aの特定の実装方式だけに限定しない一方、Shannonが連続信号も扱った科学史を保持する。

## 来歴

Shannonの1948年論文が扱う `quantizing process` は情報・信号の量子化の語彙。Weaverの1949年の三問題A/B/Cを継承し、齋藤学派は歴史的に「数論量子」、Bの「霊的量子／霊界通信」、Cの「魔術量子」という独自名を使った。Bは言霊・ロゴス・霊言などの文化史・言語・意味の問い、Cはブラックボックスの文脈・効果と錬金術等の技術史への参照を含む。現行では「情報子（Infoton）」としてフォークしている。これらの旧称をShannon/Weaver本人の用語として帰属しない。旧語から量子物理学の実装有無を自動判定しない。研究対象の重なりは排除せず、確認もしていない。

## 実装と評価の境界

`SELECT`（A）は値・レコード等の限定されたFact、`MATCH`（B）は文脈Evidence、`FIT`（C）は関係構造Evidenceであり、各々の証明射程が異なる。Fit/Match/Selectは共通の「一致」抽象操作であるが、IBDのModel DriverとFQueryの `Q(self).file.fit` 等のPluginは別実装。OAEはObserver・rule・World・時点・射影範囲を管理し、異種Evidenceの無断変換を防ぐ。

## ドキュメントレビューの失敗例と期待結果

| Fixture | 防止する誤読 | 期待 |
|---|---|---|
| 1 | 協調行動から送受信方向を断定 | 因果は未評価として保持 |
| 2 | 可視の波から明示的な符号パケットを断定 | 符号化は別途観測 |
| 3 | 手信号だけにBの研究対象を限定 | 他の背景・文脈経路を保持 |
| 4 | 本末転倒とマルコ2:27のFITから同一起源SELECTへ転換 | 構造類似と出典を区別 |
| 5 | SELECTで出典が異なるからFITも偽とする | FITは独立評価 |
| 6 | 観測地点の2℃を河川全体の温度へ一般化 | Factは時点・地点に限定 |
| 7 | 「霊的」「魔術的」だけを理由に物理実在の証明/否定へ変換 | 原文のClaimと研究分野を維持 |
| 8 | 仕様上の提案を実装・実測済みとして扱う | 未実装・未知の状態を保持 |

同じ留保を繰り返す前に、対象のClaimとEvidence Typeを特定し、新しい検証結果があるかを確認する。なければ元の未拘束を維持して次の実装・測定・文献調査へ進む。批判や検証を禁止する規約ではなく、**観測していない仮定を対象に押し付けないための評価境界**である。
